# goit-PYTHON_WEB-hw-02

# 🧑‍💻 Персональний помічник (HW02)

Домашнє завдання **#2** для курсу **GoIT Python WEB**.  
Проєкт реалізує консольного помічника для роботи з контактами: зберігання телефонів, днів народження та швидкий пошук.  
У цьому завданні ми налаштовуємо **Poetry** для керування середовищем та створюємо **Dockerfile** для запуску застосунку у контейнері.

---

## 📂 Склад проєкту

- **`main.py`** — код застосунку "Персональний помічник".
- **`pyproject.toml`** — конфігурація Poetry з фіксацією Python 3.13 та залежностей.
- **`Dockerfile`** — інструкції для створення контейнера з застосунком.
- **`README.md`** — документація проєкту.

---

## 🐍 Віртуальне середовище (Poetry)

### Використаний інструмент

- **Poetry** — для створення та керування віртуальним середовищем.
- **Python** — версія **3.13** (зафіксована у `pyproject.toml`).
